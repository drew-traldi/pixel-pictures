# 👾 Pixel Boy

Draw pixel art with retro Game Boy, PICO-8 and NES palettes, then export a crisp PNG.

**▶ Use it here: [https://drew-traldi.github.io/pixel-pictures/](https://drew-traldi.github.io/pixel-pictures/)**

- Free, no sign-up, no ads
- Runs entirely in your browser. Nothing you enter is sent to a server.
- Works on desktop and mobile

## Run it locally

It's a single HTML file. Download `index.html` and open it in any modern browser.
